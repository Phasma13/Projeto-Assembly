# Projeto-Assembly
Jogo da velha e snake feitos em asembly com funções em c

Entrar na pasta do jogo:

Bash
cd ~/jogo
Dar permissão para o arquivo rodar:

Bash
chmod +x jogos
Abrir o jogo:

Bash
./jogos
(Caso algum desses dê erro de permissão negada, use sudo chmod +x jogos no passo 2 e sudo ./jogos no passo 3).
